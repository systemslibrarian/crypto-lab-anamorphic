# Anamorphic Channel

A Crypto Lab exhibit for receiver-anamorphic public-key encryption under ordinary key
disclosure, tracked in the catalog roadmap as **A-D-15**.

This commit is the repository baseline. It carries the licence, the Node version pin and
the ignore rules, and nothing else. No lesson, construction, test or published claim exists
at this commit, and none should be inferred from the repository name.

The implementation arrives by pull request and is reviewed before anything is merged or
deployed.
